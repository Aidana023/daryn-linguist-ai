# 🤖 Daryn Linguist AI — AI or Human?
> **Научно-исследовательский проект для конкурса «Дарын»**  
> *Linguistic Analysis of AI-Generated and Human Written English*

## 📌 О проекте
Интерактивная платформа в стиле Duolingo для анализа текстов и определения: написаны они человеком или искусственным интеллектом.

## ✨ Основные функции
1. **AI vs Human Detector** — анализ метрик Perplexity, Burstiness и поиск клише (`delve`, `testament`).
2. **Multilingual Translator** — сравнение естественного человеческого перевода и шаблонного машинного.
3. **Gamified Quizzes** — интерактивные задания и тесты с баллами XP и уровнями.

## 🛠 Технологический стек
React, Tailwind CSS, JavaScript.
